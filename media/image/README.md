# 數位影像：從像素到檔案格式

## 學習目標

- 說明解析度、色彩模式、檔案大小與壓縮之間的關係。
- 讀取影像 metadata，辨識方向與拍攝資訊可能造成的呈現差異。
- 用 Python 輸出不同尺寸與格式的同一張圖片並比較結果。

## 課堂流程

| 時間 | 活動 | 產出 |
|---|---|---|
| 15 分 | 觀察同一張圖在手機、投影與網頁的顯示差異 | 兩項猜測 |
| 20 分 | 說明像素、RGB、解析度、JPEG/PNG/WebP | 規格表 |
| 35 分 | 執行小實驗，縮放與轉存圖片 | `output/` 圖檔 |
| 20 分 | 比較檔案大小與畫質 | 觀察紀錄 |
| 10 分 | metadata 與素材授權提醒 | 結論 |

## 安裝與執行

```bash
uv run --with pillow python image_lab.py sample.jpg
```

沒有 `sample.jpg` 時，先使用自己拍攝、可公開使用或課程提供的素材。不要使用未取得授權的網路圖片。

## 實驗任務

### 基礎必做

1. 執行程式，打開輸出的三張不同尺寸 JPEG。
2. 從 1200、800、400 像素中選一張你覺得最適合課堂網頁的版本，寫一句理由。

### 標準實作

1. 比較原圖、寬度 1200、800、400 像素的檔案大小與可讀性。
2. 比較 JPEG（品質 90、60）與 PNG；說明哪一種較適合照片、哪一種較適合含文字或透明背景的圖。
3. 查看 EXIF，判斷是否包含拍攝時間、裝置或 GPS 等隱私資訊；若有，說明公開前的處理方式。

### 進階挑戰

把程式改成可從命令列指定輸出寬度與 JPEG 品質；輸入錯誤路徑時，提供清楚的中文錯誤訊息。

## 繳交問題

- 為何解析度較高不一定代表網頁呈現較好？
- 你選擇的輸出格式如何平衡畫質、容量與用途？
- 這份素材是否需要移除 metadata？為什麼？
