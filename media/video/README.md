# 數位視訊：畫格、幀率、容器與編碼

## 學習目標

- 區分畫格（frame）、幀率（fps）、解析度、容器與 codec。
- 根據用途選擇輸出規格，並理解檔案大小、畫質與播放相容性的取捨。
- 以 Python 擷取指定畫格，建立可驗證的觀察結果。

## 先釐清兩個常見誤解

- **MP4 是容器，不等於 codec**：容器可裝影像、音訊、字幕與 metadata；H.264、H.265、AV1 是常見影像編碼方式。
- **fps 不等於畫質**：fps 影響動作流暢度；解析度、位元率、壓縮方式及素材本身也影響觀感。

## 小實驗

```bash
uv run --with opencv-python python video_lab.py sample.mp4
```

程式輸出影像尺寸、fps、總畫格、估計時長，並在影片的 0%、50%、90% 位置擷取畫格。若某些編碼無法讀取，應記錄播放器、作業系統與 codec 支援情況，而不是直接判定檔案損毀。

## 任務

### 基礎必做

1. 執行程式，打開開始、中段、結尾三張畫格。
2. 說出影片的尺寸與 fps，並用一句話說明 fps 代表什麼。

### 標準實作

1. 比較兩段影片的尺寸、fps、時長與容量。
2. 選一段快速移動畫面，說明低 fps 或高壓縮可能造成的視覺問題。
3. 為「手機直式短片、課堂投影、網頁嵌入」各提出一組合理輸出規格，並說明取捨。

### 進階挑戰

讓程式接受秒數而非比例，擷取指定時間點的畫格，並處理超出影片時長的輸入。

## 基本轉碼原則

轉碼會再壓縮。保留原始檔、將輸出目的說清楚，並以短片測試相容性；不要在不明確需求下反覆轉檔。
