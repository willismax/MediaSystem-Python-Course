# 數位音訊：取樣、量化與波形

## 學習目標

- 說明取樣率、位元深度、聲道與資料量的意義。
- 用波形辨識振幅、時間與失真風險。
- 比較 WAV 與常見壓縮音訊格式的使用情境。

## 核心概念

未壓縮 PCM WAV 的粗略資料量：

`秒數 × 取樣率 × 位元深度 ÷ 8 × 聲道數`

例如 10 秒、44.1 kHz、16-bit、雙聲道約為 1.76 MB。MP3/AAC 通常較小，但屬有損壓縮；WAV 適合編輯與保存中間版本。

## 小實驗

```bash
uv run --with matplotlib python audio_lab.py sample.wav
```

程式會讀取 WAV 標頭、計算時長與未壓縮估計值，並輸出波形圖。建議使用 5–15 秒、授權清楚的短音檔。

## 任務

### 基礎必做

1. 執行程式並打開波形圖。
2. 在波形中圈出一段音量較大與一段較小的位置。

### 標準實作

1. 比較兩個 WAV：取樣率、聲道、位元深度與檔案大小。
2. 找出一段音量明顯變化的位置，從波形說明原因。
3. 針對「語音備忘錄、音樂母帶、網頁背景音」各選擇一種合適格式並說明理由。

### 進階挑戰

將左右聲道各畫一張波形圖，並比較單聲道與雙聲道素材的差異。

## 繳交問題

- 取樣率提高會影響什麼？它不保證改善什麼？
- 單聲道與雙聲道各適合哪些情境？
- 何時應保留未壓縮版本？
