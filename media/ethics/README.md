# 媒體倫理與發布：來源、授權、個資與生成式媒體

## 學習目標

- 在作品發布前辨識著作權、授權、肖像與個資風險。
- 能依素材來源建立可追溯的標示。
- 對使用生成式 AI 或第三方 API 的部分做透明揭露。

## 發布前檢查表

- [ ] 我有權使用每一份圖片、音訊、視訊、字型與程式碼嗎？
- [ ] 是否記錄來源、作者、網址、授權條款與修改內容？
- [ ] 素材是否含有人臉、姓名、學號、定位、車牌、通訊紀錄或其他可辨識資訊？
- [ ] 是否取得必要的同意，或已遮蔽、移除、改用替代素材？
- [ ] 是否清楚標示生成式 AI、第三方 API 及其資料可能傳送的範圍？
- [ ] 是否避免把「網路上找得到」誤認為「可任意使用」？

## Creative Commons 快速判讀

| 標示 | 一句話理解 |
|---|---|
| CC BY | 可使用與改作，但需署名。 |
| CC BY-SA | 改作後通常須以相同條款分享。 |
| CC BY-NC | 不得作商業用途。 |
| CC BY-ND | 不得散布改作版本。 |
| CC0 | 作者放棄大部分著作權利，但仍宜保留來源紀錄。 |

授權條款有細節與例外；不確定時，選擇替代素材、向權利人確認，或暫不公開。

## 專題 README 必填欄位

```text
素材名稱：
來源與作者：
授權：
本專題如何使用／修改：
人物或個資處理：
生成式 AI／第三方 API：使用目的、傳送資料類型、人工修改：
```

## 討論案例

### 基礎必做

從自己的練習素材選一項，填完「來源與作者、授權、如何使用」三欄。

### 標準實作

以小組專題為例，找出一項「可以做但需要標示」與一項「應先取得同意或改用素材」的情境，寫出處置理由。

### 進階挑戰

為期末作品建立一份發布前檢查流程，指定由誰在何時確認素材授權、個資與 AI 揭露。
