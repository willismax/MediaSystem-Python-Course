指令小抄

第一次使用

git config --global user.name "名字"設定作者名字
git config --global user.email "信箱"設定作者 email
git init把目前資料夾變成儲存庫
git clone 網址把遠端專案整份複製下來

存檔

git status看現在的狀態，迷路時先打這個
git add 檔名、git add .把修改放進暫存區
git commit -m "訊息"把暫存區存成一個版本
git diff、git diff --staged看還沒暫存／已暫存的修改
git log --oneline看存檔歷史

復原

git restore 檔名丟掉工作目錄的修改（救不回來）
git restore --staged 檔名從暫存區拿出來，修改保留
git merge --abort放棄進行到一半的合併

分支

git switch -c 名稱建立分支並切換過去
git switch 名稱切換分支
git branch列出分支
git merge 名稱把那個分支合併進目前分支
git branch -d 名稱刪除已合併的分支

遠端

git remote add origin 網址連結遠端，取名 origin
git push -u origin 分支第一次上傳並記住對應關係
git push上傳目前分支
git fetch下載遠端更新，不動你的分支
git pull下載並合併

協作流程

開分支 → 修改 → add → commit → push → 開 Pull Request → 隊友審核 → Merge → 切回 main 再 pull。
