取樣率不夠：聽見混疊

取樣率要大於最高頻率的兩倍（Nyquist）。不夠時，取樣點會連成另一條比較慢的波，電腦就把頻率認錯了。

位元深度不夠：聲音變髒

每個 Sample 只能存成 2 的 bit 次方種數值。層級越少，波形變成越粗的階梯，多出來的誤差聽起來像沙沙聲。取樣率維持 22,050 Hz 不變。

實驗 2・10.7–10.9

Peak、RMS 與 dB

一段小聲的音，中間有一聲拍手。Peak 是最大的一瞬間，RMS 是整段的平均強度。振幅乘 2，大約加 6 dB。
