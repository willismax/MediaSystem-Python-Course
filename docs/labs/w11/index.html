剪輯聲音，就是在改數字

裁切、調音量、淡入淡出、混音、去停頓、變速變調，背後都是對一串樣本做運算。每個實驗都照同一條線走：剪輯操作 → 訊號改變 → 聽到的結果。先戴耳機、音量調小，先預測再按播放。頁面上的人聲是程式合成的示範聲音。

剪輯操作pydub 的一行程式：切片、＋6、overlay…
訊號改變樣本被取出、相乘、相加、重新排列
聽到的結果變短、變大聲、喀聲、破音、變尖…

實驗 2・11.1、11.7
增益：每個樣本乘同一個數

      
調音量就是乘法：新樣本 ＝ 樣本 × 10dB/20。+6 dB 約等於乘 2，−6 dB 約等於乘 0.5。乘完超過 ±1 的部分存不下，會被削平。

紅線：±1（0 dBFS），超出的樣本被削平並標成紅色

實驗 3・11.1、11.8
淡入淡出：隨時間變化的增益

      
淡入是把樣本乘上一條從 0 慢慢升到 1 的曲線（包絡）。切在波形中間時，聲音瞬間從 0 跳到某個值，就會聽到「喀」；淡入幾十毫秒就能消掉。Crossfade 則是前一段淡出、後一段淡入，兩段重疊相加。

實驗 4・11.2–11.3、11.7
混音：逐點相加，小心削波

      
voice.overlay(bgm) 把兩段樣本逐點相加。兩段各自都沒有超過 0 dBFS，加起來卻可能超過。混音前先把各軌調小，留一點空間（headroom）。

實驗 5・11.4、11.13–11.15
三種「正規化」不是同一件事

      
Peak 正規化看最大的一瞬間；平均 dBFS 調整看整段 RMS（停頓也算進去）；LUFS 是依人耳加權、並排除太小聲片段的響度。同一段錄音，三種方法給的增益可能差很多。

    

      

        
來源

        
試聽

        

        
動手：比較「有長停頓」和「停頓已壓縮」：平均 dBFS 法給的增益差多少？哪一種方法會讓 max dBFS 超過 0？這就是 11.13 說「長停頓會拉低平均值」的意思。

      

      

        

        
LUFS 是簡化版：單聲道、BS.1770 的 K 加權與兩段門檻，數字可能和專業響度表差一點。

實驗 9・11.20
濾波：只動某一段頻率

      
這段錄音混了 60 Hz 的電源嗡嗡聲和高頻嘶嘶聲。High-pass 讓高於截止頻率的聲音通過，用來去低頻；Low-pass 讓低於截止頻率的通過，用來去高頻。回想第十章的頻譜：濾波就是改頻譜的形狀。

    

      

        
        
        
濾波器斜率

        

        

        
動手：High-pass 拉到 100 Hz，嗡嗡聲還在嗎？說話聲有沒有變？Low-pass 拉到 1,500 Hz，嘶嘶聲沒了，但人聲聽起來像隔著什麼？pydub 的濾波器是一階，斜率很緩，切換成四階比較看看。

      

      
頻譜（對數頻率軸）：灰線是原始，橘線是濾波後，虛線是截止頻率
