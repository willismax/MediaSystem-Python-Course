實驗 3・13.10
YUV 與 Chroma Subsampling

      
影片常把顏色拆成亮度 Y 和兩個色差 Cb、Cr。人眼對亮度細節比較敏感，所以色差可以降低解析度：4:2:0 是每 2×2 個 Pixel 共用一組 Cb、Cr。yuv420p 是 Pixel Format，不是解析度，也不是 Codec。

幀內壓縮：轉換、量化、丟掉小係數

      
把畫面切成 8×8 的小方塊，用 DCT 轉成「頻率係數」：左上角是整塊的平均亮度，越往右下越是細節。量化時把係數除以一個步長再四捨五入，小係數就變成 0，像 13 4 2 1 0.5 → 13 4 0 0 0。真正丟資訊的就是這一步。

實驗 8・13.16–13.17、13.22–13.24
ffprobe 解讀器：做一張影片的技術身分證

      
不要看副檔名或播放器猜格式。用講義 13.23 的指令拿到 JSON，貼到這裡，就會拆出 Container 裡有哪些 Stream，並整理成 Video Technical Card。

    

      

        
範例

  -show_entries \
  stream=index,codec_type,codec_name,width,height,pix_fmt,r_frame_rate,avg_frame_rate,bit_rate,sample_rate,channels:format=format_name,duration,size,bit_rate \
