第八章的 LoRA 要「凍結權重 W，只學 ΔW」。在那之前，先弄清楚權重是什麼、訓練在改什麼、推論時為什麼權重不會變，以及大語言模型和 RAG 怎麼運作。下面每個實驗都可以直接動手改。

實驗 4・0.4

考得好，就是真的會嗎？

實心點是訓練資料，空心點是模型沒看過的驗證資料。模型越複雜（多項式次數越高），越能貼著訓練點走，但不一定猜得準新的點。

動手：把次數拉到 12，看訓練誤差和驗證誤差怎麼變。再把訓練資料加到 60，過擬合有改善嗎？

實驗 5・0.6–0.7

大語言模型：預測下一個 Token

這是一個用 24 句課程句子訓練的玩具語言模型，只看前一個詞來猜下一個（Bigram）。真正的 LLM 看得更長、模型大得多，但推論的迴圈相同：算機率、挑一個、接上去、再預測。

動手：點右邊的機率條自己選下一個詞。把 Temperature 調到最低，每次生成都一樣嗎？調到最高呢？推論時模型的權重（這張機率表）有沒有變？
