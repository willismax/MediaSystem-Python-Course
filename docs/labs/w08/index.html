實驗 1・8.4–8.5

LoRA 到底省了多少參數？

LoRA 不改原本的權重 W，只學一個更新量 ΔW＝B×A。B 是 d×r、A 是 r×k，r 越小，要學的數字越少。

動手：先預測 r 加倍時參數量會變幾倍，再拖動滑桿驗證。講義的例子是 4096×4096、r＝16。
完整微調要學的參數 d×k
LoRA 要學的參數 r(d+k)
占完整微調的比例

簡化例子：只算單一矩陣。真實模型有很多層，LoRA 也不一定加在每一層，總參數量依設定而定。

實驗 2・低秩直覺

只留前 k 個成分，圖還認得出來嗎？

一張 64×64 的圖就是一個矩陣。用奇異值分解（SVD）只保留前 k 個成分，等於用「rank k」去近似它。LoRA 押的就是：模型需要的更新量，常常用低 rank 就表示得差不多。

動手：在左邊畫布上自己畫（拖曳滑鼠或手指）。橫線、直線這類規律的圖，k 很小就能還原；雜亂的塗鴉要多少 k？
保留的能量（Σσ² 比例）
要存的數字 k(64+64+1) ／ 4096

實驗 4・8.12–8.14

模型學到的是角色，還是背景？

訓練資料裡，角色 A 永遠站在白牆前、角色 B 永遠在森林。背景比臉好認，模型就可能抄捷徑。測試時把背景對調，看它還認不認得出角色。

動手：先預測 0% 時「背景對調」測試的正確率，再慢慢加到 50%。正確率在哪裡開始明顯回升？只增加圖片數量、不加多樣性，有用嗎？
