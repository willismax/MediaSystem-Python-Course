## W01 共用筆記建立方式

1. 在 HackMD 建立一份空白筆記。
2. 開啟「Versions and GitHub Sync」。
3. 將筆記連結到 `course-115/week-01-hackmd-markdown.md`。
4. 從 `course-115-hackmd-materials` 分支拉入內容；PR 合併後改連結 `main`。
5. 用閱讀模式檢查程式碼區塊、Mermaid、連結與分享權限。
6. 把閱讀連結填回兩個首頁的 `<W01_COMMON_NOTE_URL>`。
