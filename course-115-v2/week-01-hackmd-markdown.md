# 多媒體系統 W01｜HackMD、Markdown 與第一份媒體筆記

:::info
本週任務：建立一份自己的 HackMD 筆記，使用 Markdown 整理一個多媒體案例，並交出分享連結。
:::

## 一、這門課要做什麼？

這門課會使用 Python 與 AI 工具處理影像、聲音與影片，最後完成一個可以操作的多媒體應用。

AI 可以協助寫程式與除錯，但每位同學都要能回答：

- 輸入資料是什麼？
- 程式做了哪些處理？
- 輸出結果如何判斷正確？
- 哪一部分由 AI 協助？你怎麼驗證？

## 二、為什麼第一週先學 Markdown？

Markdown 是一種純文字標記方式。文字本身仍看得懂，同時可以呈現標題、清單、連結、圖片、表格與程式碼。

這學期會用 Markdown 撰寫：

- 課堂筆記
- 實作步驟
- GitHub README
- 專題規格
- 測試與除錯紀錄
- AI 使用紀錄

學 Markdown 的目的不是背語法，而是把技術工作整理成別人看得懂、自己日後也能重現的文件。

## 四、Markdown 基本語法

### 1. 標題

```markdown
# 第一層標題
## 第二層標題
### 第三層標題
```

一份筆記原則上只使用一個第一層標題，再用第二、第三層標題整理內容。

### 2. 段落與強調

```markdown
這是一個段落。

這是第二個段落，**這段文字需要強調**，這是 `檔名或指令`。
```

### 3. 清單與待辦事項

```markdown
- 影像
- 聲音
- 影片

1. 取得素材
2. 處理素材
3. 輸出結果

- [x] 建立筆記
- [ ] 完成作業
```

### 4. 連結與圖片

```markdown
[課程程式庫](https://github.com/willismax/MediaSystem-Python-Course)

![替代文字](圖片網址)
```

替代文字應簡短描述圖片內容，不能只寫「圖片」。如果圖片無法顯示，讀者仍可從文字知道原本要表達什麼。

### 5. 引用

```markdown
> 這是一段引用或需要特別標示的內容。
```

### 6. 程式碼

````markdown
```python
message = "Hello, multimedia!"
print(message)
```
````

反引號後方標示 `python`、`bash` 或 `json`，可以讓程式碼更容易閱讀。

### 7. 表格

```markdown
| 檔案 | 類型 | 用途 |
|---|---|---|
| photo.jpg | 影像 | 活動照片 |
| voice.wav | 聲音 | 語音辨識測試 |
| demo.mp4 | 影片 | 專題展示 |
```

表格適合比較固定欄位，不要為了排版把每一段文字都塞進表格。

## 六、班別活動

### 基礎練習

兩人一組交換筆記，檢查：

1. 標題層級是否清楚。
2. 圖片是否有替代文字。
3. 連結是否可以開啟。
4. 表格內容是否完整。
5. 是否誤放個資或不適合公開的資料。

完成後，在同學筆記留下「一項看得懂的地方」與「一項需要補充的地方」。

### 延伸挑戰

從工作、社團或生活經驗選一個流程，用 Mermaid 畫出媒體資料如何流動。

````markdown
```mermaid
flowchart LR
    A[取得影像或聲音] --> B[處理]
    B --> C[儲存]
    C --> D[分享或播放]
```
````

再補充兩個問題：

- 哪一步最可能遇到格式不相容？
- 哪一步可能涉及個資或著作權？

## 七、繳交方式

請繳交 HackMD 閱讀連結。繳交前以無痕視窗測試，確認持有連結者可以開啟。

- 連結權限正確。
