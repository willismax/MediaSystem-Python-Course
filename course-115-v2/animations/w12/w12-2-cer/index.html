CER 怎麼算

Character Error Rate：字元錯誤率（越低越好）

1逐字對齊，數錯幾個
CER= (S + D + I) / NN = 參考答案的字數
= (1 + 0 + 0) / 6 ≈0.0%
S 替換・D 刪除・I 插入：把參考答案改成辨識結果，最少要改幾次
2三種錯誤：S、D、I
S替換Substitution
一個字被換成別的字
音 → 言
D刪除Deletion
參考有、辨識漏掉的字
少了「習」
I插入Insertion
辨識多出來的字
多了「的」
每個例子都是 1 / 4 = 25%I 很多時，CER 甚至會超過 100%
3先正規化，再算
正規化前(4 S + 3 D) / 15 ≈46.7%大小寫、空白、句號都被算成錯
規則去空白・去標點・英文轉小寫
正規化後0 / 12 =0%兩邊都變成 stft的視窗是2048
同一組結果，CER 差很多 → 報告 CER 時，要寫出用了哪些規則
4為什麼中文用 CER，不用 WER？
英文today␣I␣study␣speech空白就是詞的邊界
中文今天學習語音沒有空白：詞要靠「斷詞」，斷法不只一種
斷法 A今天學習語言WER = 1 / 3 ≈ 33.3%
斷法 B今天學習語言WER = 1 / 2 = 50%
逐字今天學習語言CER = 1 / 6 ≈ 16.7%
斷詞一變，WER 就變 → 中文常用 CER，不受斷詞影響
辨識結果都是「今天學習語言」，參考答案是「今天學習語音」
