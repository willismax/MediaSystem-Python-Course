Podcast 自動剪輯器

把錄音裡的長停頓剪短、音量拉齊、加上片頭片尾

1偵測非靜音段
thresh = audio.dBFS - 14平均 −24 dBFS − 14 → 門檻 −38 dBFS
detect_nonsilent(audio, min_silence_len=800, silence_thresh=thresh)
2長停頓壓成 300 ms
gap = AudioSegment.silent(duration=300)頭尾的靜音直接丟掉
out = chunks[0] + gap + chunks[1] + gap + …
3平均音量調到 −18 dBFS
change = -18.0 - out.dBFS−18 − (−23.1) = +5.1 dB
out = out.apply_gain(change)整段乘同一個倍數，大小聲的相對關係不變
4淡入 300 ms／淡出 800 ms，加片頭片尾
out = out.fade_in(300).fade_out(800)
final = intro + out + outro片頭 3.0 s、片尾 2.5 s（示範）
5匯出 MP3
podcast_result.mp3
MP3・192 kbps・41.3 s
62.0 s → 41.3 s（短了 33%）
final.export("podcast_result.mp3", format="mp3", bitrate="192k")
